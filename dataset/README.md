# PAN12 Dataset

## Dataset Overview
This project uses the PAN12 dataset for research on online grooming detection.

## Purpose
- Analyse online conversations.
- Identify potential grooming-related behavioural patterns.
- Support manual annotation and contextual analysis.

## Dataset Contents
The dataset contains conversation-level messages and author information.

## Data Availability
The original PAN12 dataset is maintained locally due to privacy and data-handling considerations. It is not included in this repository.

Access and use must follow the dataset licence and applicable research permissions.
