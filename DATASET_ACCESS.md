# PAN12 Dataset Access

## Dataset Name
PAN12 Sexual Predator Identification Dataset

## Purpose
The dataset is used for academic research and development of the LLM-Based Grooming Detection Framework.

## Dataset Usage
- Conversation-level message analysis.
- Inspection and preprocessing of conversational data.
- Research on potential grooming-related behavioural patterns.
- Manual annotation and contextual analysis.

## Data Availability
The original PAN12 dataset is maintained locally and is not uploaded to this public repository due to data privacy, licensing and usage restrictions.

Researchers should obtain the dataset from its authorised source and follow the applicable licence and research conditions.

## Note
This repository contains dataset documentation only, not the original conversation records.
