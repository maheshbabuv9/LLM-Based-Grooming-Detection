# PAN12 Dataset Access

## Dataset Name
PAN12 Sexual Predator Identification Corpus (2012).

## Dataset Description
The PAN12 dataset is used for research on online sexual predator identification. It contains online conversations that support the study and development of grooming detection systems.

## Dataset Usage in This Project
The dataset is used for:
- Conversation loading and preprocessing.
- Message extraction and organisation.
- Predator identification analysis.
- Contextual analysis using Large Language Models.
- Experimental grooming detection.

## Dataset Statistics

### Training Dataset
- Total Conversations: 66,927
- Total Messages: 903,607
- Unique Authors: 97,689
- Predator IDs: 142
- Conversations Containing Predators: 2,016

### Testing Dataset
- Total Conversations: 155,128
- Total Messages: 2,058,781
- Unique Authors: 218,702
- Predator IDs: 254
- Annotated Conversations: 834
- Annotation Rows: 6,478

The original dataset files are maintained separately in the local project environment. Sensitive conversation records and annotation files are not included in this public repository.
